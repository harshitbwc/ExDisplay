Your Android tablet,
as a real Mac display.

ExDisplay turns an Android tablet into a wired, touch-enabled extended display for your Mac. Not a mirror: macOS sees an extra screen it can put windows on, and touching the tablet drives the cursor.

Download for Mac Download Android app

Apple Silicon Mac (macOS 14+) and an Android 8.0+ tablet · all releases

Why it's different

A true extended display

Drag windows onto it from System Settings → Displays, like any monitor. It is a software-only virtual display, so it works alongside your physical monitors and doesn't use up a display output.

Wired over USB

Video and touch travel over your USB cable. No Wi-Fi, no pairing, nothing exposed to your network.

Trackpad-style touch

One finger moves and clicks, two fingers scroll, three fingers swipe between Spaces or open Mission Control.

Private by design

No accounts, no telemetry, no servers. Only the virtual display is captured, never your other screens.

How it works

A USB-C cable alone can't make a tablet a display, so ExDisplay uses the cable as a data pipe and does the rest in software.

Install

You need a Mac, an Android tablet, a data-capable USB cable and adb.

  1. Prepare the tablet

    Enable USB debugging: Settings → About → tap Build number 7 times, then Developer options → USB debugging. Plug the tablet in and accept the "Allow USB debugging?" prompt.

    brew install android-platform-tools
adb devices        # your tablet should be listed as "device"

  2. Install the Mac app

    Download ExDisplay-<version>-mac-arm64.zip from the latest release, unzip it and move ExDisplay.app to /Applications.

    The app is ad-hoc signed, not notarized by Apple, so macOS blocks the first launch. On macOS 15 or later, open System Settings → Privacy & Security and choose Open Anyway, or run:

    xattr -dr com.apple.quarantine /Applications/ExDisplay.app

    ExDisplay lives in the menu bar. Click each ⚠️ item to grant Screen Recording and Accessibility, then quit and reopen it.

  3. Install the Android app

    Download ExDisplay-<version>-android.apk from the same release and install it:

    adb install -r ExDisplay-<version>-android.apk

    Always use the Mac and Android apps from the same release.

  4. Open the tablet app

    It connects automatically. The dot in the corner turns green, and a new display appears in System Settings → Displays where you can arrange it.

Prefer to build it yourself? See the build-from-source steps. Each release includes SHA-256 checksums.

Touch works like a trackpad

GestureAction on the Mac
1 finger tap / dragClick / drag the cursor
1 finger moveMove the cursor
2 fingers panScroll
3 fingers swipe ← / →Next / previous Space
3 fingers swipe ↑Mission Control
3 fingers swipe ↓App Exposé

Three-finger swipes use Mission Control's keyboard shortcuts, so they need more than one Space and those shortcuts enabled (both are the macOS defaults).

Limitations & FAQ

Why can't I watch Netflix or Apple TV+ while it's running?

macOS blocks DRM-protected playback system-wide whenever a screen capture session is active. Use Pause Streaming in the menu bar to watch, then resume.

Is it safe? What does it capture?

Only the virtual display is captured, and everything stays on your machine: the server listens on loopback only, and there is no telemetry. See the security and privacy notes.

Will it keep working after macOS updates?

The virtual display uses an undocumented Apple API (CGVirtualDisplay). It works today, but a future macOS release could break it. It also means ExDisplay can never be on the Mac App Store.

Can I use it wirelessly, or with an Intel Mac?

Not currently. It is wired-only and built for Apple Silicon. Pinch-zoom and rotate gestures aren't supported either.

Something isn't working.

Open Show Logs from the menu bar and check the troubleshooting guide. If that doesn't help, open an issue with your Mac and tablet models and the copied logs.
